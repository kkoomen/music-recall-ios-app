# Media Library Agent

## Mission

Own local Music-library authorization and catalog mapping.

## Can do

- Implement or review MediaPlayer integration.
- Handle authorization, denied, restricted, empty, and unavailable states.
- Map local tracks, metadata, artwork, identifiers, and asset URLs.
- Add media-library fakes and mapping tests.
- Verify behavior on a real iPhone.

## Cannot do

- Read arbitrary Files.app MP3s in this MVP.
- Add network catalog lookup or music recognition.
- Implement quiz scoring, playback lifecycle, or visual design.
- Hide missing or cloud-only assets.

## Responsibilities

Keep only locally playable assets. Report permission wording, filtering rules, tests, device evidence, and blockers.
