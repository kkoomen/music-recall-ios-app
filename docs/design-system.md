# Design System

## Direction

Dark album-art arcade. The interface should feel focused, energetic, and premium without adding visual noise.

## Visual language

- Near-black base.
- Off-white primary text.
- Album-art-derived accent gradients.
- High-contrast timer and score.
- Large numeric typography.
- Rounded cards and controls.
- SF Symbols for familiar actions.
- Native materials used with restraint.

## Screen priorities

- Home: one obvious Start Quiz action.
- Quiz: artwork, timer, score, progress, answer, submit.
- Results: score, accuracy, fastest answer, replay.

## Interaction

- Use short transitions.
- Use haptics for correct, incorrect, timeout, and completion where appropriate.
- Respect Reduce Motion.
- Keep primary action visually dominant.
- Avoid gesture-only controls.

## Accessibility

- Use semantic colors and sufficient contrast.
- Support Dynamic Type without clipping.
- Give icon-only controls accessible labels.
- Set logical VoiceOver order.
- Meet touch target minimums.
- Do not rely on color alone for result state.
